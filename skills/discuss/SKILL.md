# Discuss

## Goal

Get the agreement of the user on one approach before you make a change. The user decides from evidence, not from imagination.

## What to show

1. What occurs and why, with evidence.
2. The options that are real. For each option, show the cost, the risk, and what it does not solve.
3. Your recommendation and the reason.
4. The decisions that only the user can make.

Show concrete evidence, for example code snippets, mocks, diagrams, and screenshots.

## Rules

- Disagree with weak arguments. Change your recommendation when the user gives a good argument.
- When the user decides, do not argue again.
- The discussion is complete only when the user agrees on a specific approach and scope.
