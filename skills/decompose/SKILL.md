# Decompose

## Goal

Change a spec into tickets that agents can do one by one.

## Steps

1. **Split the spec.** Each ticket gives one result that you can see.
2. **Find the dependencies.** Put the tickets in order.
3. **Select a role for each ticket.** Select the role that matches the work.
4. **Show the plan to the user.** Get approval before you create the tickets.
5. **Create the tickets.** Use the `ticket` skill.

## Rules

- Do not make tickets that only add scaffolding.
- For each ticket, write what it does not include.
